## 🚀 ダッシュボードを起動する

### 方法1: 自動起動スクリプト（推奨）

```bash
./run_dashboard_venv.sh
```

このスクリプトが自動的に：
1. 仮想環境をアクティベート
2. デモデータを生成（必要な場合）
3. ダッシュボードを起動

### 方法2: 手動実行

```bash
# 1. 仮想環境をアクティベート
source venv/bin/activate

# 2. デモデータを生成
python quick_start_dashboard.py

# または既存データを使う場合
# python dashboard.py --data demo_output
```

### アクセス方法

ダッシュボードが起動したら、ブラウザで以下を開く：

```
http://127.0.0.1:8050
```

## 📋 基本コマンド

### 仮想環境の操作

```bash
# アクティベート（有効化）
source venv/bin/activate

# プロンプトが (venv) になります
(venv) $ 

# アクティベート中は通常のpythonコマンドが使えます
(venv) $ python main.py demo
(venv) $ python dashboard.py

# ディアクティベート（無効化）
deactivate
```

### デモを実行

```bash
source venv/bin/activate
python main.py demo
```

出力先: `demo_output/`

### ダッシュボードを起動

```bash
source venv/bin/activate
python dashboard.py --data demo_output
```

### 独自データで分析

```bash
source venv/bin/activate

# 分析を実行
python main.py analyze your_data.gpkg --output results/mydata

# ダッシュボードで確認
python dashboard.py --data results/mydata
```

## 🛠️ トラブルシューティング

### ❓ 仮想環境がアクティベートできない

```bash
# パスを確認
ls venv/bin/activate

# 存在しない場合は再作成
./setup_venv.sh
```

### ❓ モジュールが見つからない

```bash
# 仮想環境がアクティベートされているか確認
which python
# → /Users/.../three_indicator/venv/bin/python となっていればOK

# アクティベートされていない場合
source venv/bin/activate
```

### ❓ ポートが使用中

```bash
# 別のポートで起動
python dashboard.py --port 8888
```

ブラウザで `http://127.0.0.1:8888` を開く

### ❓ ダッシュボードが表示されない

1. ターミナルのエラーメッセージを確認
2. データディレクトリが存在するか確認:
   ```bash
   ls demo_output/
   ```
3. デモデータを再生成:
   ```bash
   python quick_start_dashboard.py
   ```
